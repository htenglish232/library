Unit 17: Comparatives

GRAMMAR POINT: Cấp so sánh hơn của tính từ

• Cấp so sánh hơn của tính từ dùng để so sánh hai đối tượng: Tính từ cấp so sánh hơn + than + đối tượng so sánh ("so với ... thì ... hơn").

1. Tính từ 1 âm tiết: + er

long ➔ longer, fast ➔ faster

2. Tận cùng bằng -e: + r

large ➔ larger, nice ➔ nicer

3. Phụ âm + y: y ➔ i + er

pretty ➔ prettier, easy ➔ easier

4. Nguyên âm + phụ âm đơn: gấp đôi + er

big ➔ bigger, hot ➔ hotter

5. Tính từ từ 2 âm tiết trở lên: more + adj

beautiful ➔ more beautiful, expensive ➔ more expensive
