Unit 23: There Is / There Isn't / Is There ...?

📞 Hotline: 0962240866
Phần 1 • Lý thuyết Ngữ pháp

📖 Tóm tắt Trọng tâm Ngữ pháp Unit 23

Hệ thống hóa toàn bộ quy tắc sử dụng There is / There are, phân biệt nguyên tắc đi kèm với a/an, some (câu khẳng định) và any (câu phủ định & nghi vấn).

1. Danh từ Đếm được Số ít
There is + a / an + N(số ít)
  • • Khẳng định: There is a watch. / There is an apple.
  • • Phủ định: There isn't an orange.
  • • Nghi vấn: Is there a balloon?
2. Danh từ Đếm được Số nhiều
There are + (some/any) + N(số nhiều)
  • • Khẳng định: There are two apples. / some books.
  • • Phủ định: There aren't any pencils.
  • • Nghi vấn: Are there any eggs?
3. Danh từ Không đếm được
There is + (some/any) + N(không đếm được)
  • • Khẳng định: There is some milk. / some bread.
  • • Phủ định: There isn't any butter. / any cheese.
  • • Nghi vấn: Is there any homework?

⚡ Bộ Mô phỏng Ghép câu Ngữ pháp Tự động

Thay đổi các tùy chọn bên dưới để xem hệ thống tự động sinh ra câu đúng ngữ pháp chuẩn xác:

Mẫu câu hoàn chỉnh thu được
There is a watch.
Quy tắc: Dùng "There is a" với danh từ đếm được số ít.
