GRAMMAR POINT (Lý Thuyết Trọng Tâm)

Nhấp vào biểu tượng loa để nghe phát âm từng từ vựng

1. Hầu hết danh từ: Thêm -s vào sau danh từ số ít.
2. Kết thúc bằng -s / -x / -sh / -ch: Thêm -es.
3. Kết thúc bằng -f / -fe: Đổi -f/-fe thành -v rồi thêm -es.
4. Kết thúc bằng phụ âm + y: Đổi -y thành -i rồi thêm -es.
+ s + es f, fe ➔ v + es consonant + y ➔ i + es
